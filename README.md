# SXNG · Música y emociones

Cuestionario web del proyecto de tipografía experimental SXNG. Se publica con GitHub Pages.

- `index.html`, `app.js`, `styles.css`, `config.js`, `favicon.svg`: la web.
- `audio/`: fragmentos de 15 segundos (no hay canciones completas).
- `clips.json`: datos de cada fragmento.
- `config.js`: contiene la dirección del Google Apps Script que guarda las respuestas.

Las respuestas de las personas participantes NO están en este repositorio: se guardan en una hoja de Google privada.
